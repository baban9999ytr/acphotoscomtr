# Demo fotoğrafları

`public/demo/` içindeki spor görselleri ACPhotos önizlemesi için OpenAI ImageGen ile üretildi. Bunlar kurgusal örnek görsellerdir; Arda Cesurtürk'ün çekimleri veya ACPhotos müşteri işleri değildir. Eski ACPhotos sitesinden görsel alınmadı.

Önizleme bu görselleri sayfada, açıklamalarda ve alternatif metinlerde açıkça demo olarak belirtir.
